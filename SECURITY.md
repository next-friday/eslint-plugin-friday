# Security policy

## Supported versions

The package is currently unreleased at `0.0.0`. Security fixes apply to the current source on the default development line.

After the First Release, only the latest published release receives security updates. Earlier releases and prerelease versions are not supported.

| Package                             | Current state        |
| :---------------------------------- | :------------------- |
| `@next-friday/eslint-plugin-friday` | `0.0.0` (unreleased) |

## Report a vulnerability

Do not report security vulnerabilities in public GitHub issues.

1. Use [GitHub Private Vulnerability Reporting](https://github.com/next-friday/eslint-plugin-friday/security/advisories/new).
2. Or email `security@next-friday.com`.
3. Include reproduction steps, the affected rule or package version or commit, relevant configuration, and environment details. Remove secrets and private data.

### Response targets

- **Acknowledgment:** Within 48 hours.
- **Assessment:** Within 5 business days, including severity and impact.
- **Fix and advisory:** For critical issues, publish a fix and GitHub Security Advisory as soon as practical when a release applies.
